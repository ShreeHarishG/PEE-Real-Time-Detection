# API Documentation

The EdgeVision backend uses FastAPI. The following real endpoints are available:

## Core API Endpoints

### 1. `GET /api/v1/zones`
- **Purpose**: Fetch all configured safety zones and their required PPE.
- **Response**: List of Zone objects.

### 2. `POST /api/v1/zones`
- **Purpose**: Create a new safety zone configuration.
- **Request**: Zone object with polygon vertices and required PPE.
- **Response**: Created Zone object.

### 3. `PUT /api/v1/zones/{zone_id}`
- **Purpose**: Update an existing zone.

### 4. `GET /api/v1/cameras`
- **Purpose**: Fetch all registered cameras.

### 5. `POST /api/v1/videos/upload`
- **Purpose**: Upload a test video for processing.
- **Request**: Multipart file payload.
- **Response**: Video ID and file path.

### 6. `POST /api/v1/jobs/{video_id}/process`
- **Purpose**: Trigger the `pipeline.py` inference job on an uploaded video.
- **Response**: Job ID and initial status.

*(Note: The full `openapi.json` can be dynamically generated by starting the backend application and accessing `/openapi.json` via the FastAPI instance.)*
