# TensorRT Deployment Guide for NVIDIA Jetson

This guide details how to compile the YOLOv8 ONNX models into TensorRT engines for deployment on an NVIDIA Jetson device (e.g., Jetson Orin Nano, AGX Orin) running JetPack 5.x or newer.

## Prerequisites

Ensure your Jetson device has the following installed:
- JetPack (L4T)
- NVIDIA TensorRT
- DeepStream SDK (version compatible with your JetPack)

## Step 1: Transfer ONNX Models
Transfer the `ppe_v3_hn_best.onnx` and `yolov8n.onnx` files (generated by `export_onnx.py`) to your Jetson device.

## Step 2: Build FP16 TensorRT Engine using trtexec
NVIDIA provides the `trtexec` command-line tool to build and benchmark TensorRT engines.

Run the following command to build the engine with FP16 precision (recommended for best balance of accuracy and performance on Jetson):

```bash
/usr/src/tensorrt/bin/trtexec --onnx=ppe_v3_hn_best.onnx \
                              --saveEngine=ppe_v3_hn_best_fp16.engine \
                              --fp16 \
                              --workspace=4096 \
                              --verbose
```

### Parameters explained:
- `--onnx`: Input ONNX file path.
- `--saveEngine`: Output engine file path.
- `--fp16`: Enables FP16 precision.
- `--workspace=4096`: Allocates 4GB of GPU workspace memory for builder optimizations.

## Step 3: Benchmarking (Optional)
You can run a quick benchmark of the generated engine on the Jetson to estimate FPS:

```bash
/usr/src/tensorrt/bin/trtexec --loadEngine=ppe_v3_hn_best_fp16.engine \
                              --avgRuns=100
```
This will output the P95 latency and average throughput (FPS).

## Step 4: INT8 Calibration (Experimental)
If you require higher FPS and want to use INT8 precision, you must provide calibration images to maintain accuracy. DeepStream can handle INT8 calibration natively by providing a calibration file in the DeepStream configuration.

## Step 5: Integration with DeepStream / Pipeline
Once the `.engine` files are generated, update your pipeline configuration (or DeepStream `config_infer.txt`) to point to the new `.engine` files instead of the `.pt` files.
