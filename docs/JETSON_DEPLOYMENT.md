## 4. ONNX Export (on Development Machine)
Run this on your **development machine** (not on the Jetson) to generate the ONNX file:
```bash
python scripts/export_onnx.py --model models/ppe_v3_hn_best.pt --imgsz 512
```
This creates `models/ppe_v3_hn_best.onnx`.

Transfer the ONNX file to the Jetson:
```bash
scp models/ppe_v3_hn_best.onnx nvidia@<JETSON_IP>:/opt/edgevision/notebook/models/
```

---

## 5. TensorRT FP16 Engine Generation (on Jetson)
> **IMPORTANT:** The TensorRT `.engine` file must be generated **on the target Jetson device**. An engine compiled on a different platform is not portable.

```bash
chmod +x scripts/build_tensorrt.sh
./scripts/build_tensorrt.sh
```

This script runs:
```bash
/usr/src/tensorrt/bin/trtexec \
    --onnx=models/ppe_v3_hn_best.onnx \
    --saveEngine=models/ppe_v3_hn_best.engine \
    --fp16 \
    --workspace=4096
```

---

## 6. trtexec Benchmark Command
After engine generation, benchmark with:
```bash
chmod +x scripts/benchmark_tensorrt.sh
./scripts/benchmark_tensorrt.sh
```

Which runs:
```bash
/usr/src/tensorrt/bin/trtexec \
    --loadEngine=models/ppe_v3_hn_best.engine \
    --avgRuns=100
```

Run `tegrastats` in a separate terminal to monitor GPU, CPU, and thermal load simultaneously.

## 9. Startup Service (systemd)
A systemd service unit is provided at `scripts/edgevision.service`.

Install on Jetson:
```bash
sudo cp scripts/edgevision.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable edgevision
sudo systemctl start edgevision
```

Check status:
```bash
sudo systemctl status edgevision
journalctl -u edgevision -f
```

## 10. Troubleshooting

| Problem | Likely Cause | Fix |
| :--- | :--- | :--- |
| `trtexec not found` | trtexec path differs on device | Use `find / -name trtexec 2>/dev/null` to locate |
| Engine fails to load | Engine compiled on different device | Recompile engine on target Jetson |
| FPS < 12 | Max clocks not set | Run `sudo jetson_clocks` to max out clocks |
| CUDA out of memory | Model too large for VRAM | Reduce `--workspace` in `trtexec` to 2048 |
